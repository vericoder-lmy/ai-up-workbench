AI_UP 数字人口播工作台 · 安装说明
====================================

这是什么
--------
在你自己电脑上运行的数字人口播工具：
写文案 → 用你克隆的声音逐句配音（每句可调情绪、语速）→ 数字人对口型 → 自动剪辑（字幕、重点词、信息卡片、画中画、推镜、音效）
→ 同时出竖屏和横屏成片，并各生成一张写好标题的封面。

如果你有 AI 助手（Claude Code、Cowork 等），直接把整个 aiup-workbench 文件夹交给它，说“帮我装好这个工作台”，
它会按 SKILL.md 一步步带你装。下面是自己动手安装的步骤。


使用前请注意
------------
1. 只能克隆你本人，或者已经明确授权给你的人的形象和声音。不要克隆明星、公众人物或任何没授权的人。
2. 发布到抖音等平台时，在发布页勾选“内容由 AI 生成”声明。


第 0 步：确认电脑配置
---------------------
- 系统：Windows 10 或 Windows 11
- 显卡：NVIDIA 显卡，显存 4GB 以上（RTX 3050 4GB 实测能跑），显卡驱动更新到最新
- 内存：16GB 起，32GB 更稳
- 硬盘：C 盘至少留 20GB 空闲（C 盘太满会导致渲染时报内存错误）
- 网络：能正常上网（第一次启动要下载依赖）


第 1 步：放好文件
-----------------
1. 把压缩包解压，进入 aiup-workbench 文件夹，里面的 source 文件夹就是工作台本体。
2. 把 source 文件夹复制到你想放的位置，并改名，例如：D:\AI_UP
   - 路径里可以有中文
   - 不要放在 OneDrive / 网盘同步目录里
下面说的“工作台文件夹”都指这个 D:\AI_UP。


第 2 步：安装 Python
--------------------
1. 到 Python 官网（python.org）下载 Python 3.10 或更新版本的 Windows 安装包。
2. 安装时，第一个界面最下面的 “Add python.exe to PATH” 一定要勾上，再点 Install Now。
3. 装完后按 Win+R，输入 cmd 回车，在黑色窗口里输入 python --version，能看到版本号就说明装好了。


第 3 步：安装 Docker Desktop 和 HeyGem（对口型）
-----------------------------------------------
对口型用的是开源项目 HeyGem（现在叫 Duix.Avatar），它跑在 Docker 里。这一步最花时间，请耐心。

1. 到 Docker 官网下载安装 Docker Desktop for Windows，安装时选择使用 WSL 2。
   装完重启电脑，打开 Docker Desktop，等左下角显示正在运行（Engine running）。
2. 在 GitHub 搜索 Duix-Avatar（或 HeyGem），打开官方仓库，按里面的 Docker 部署说明安装。
   - 我们只用到“对口型”（face2face）服务，装好后在浏览器打开 http://127.0.0.1:8383 能有响应即可。
   - 官方镜像比较大，下载需要一段时间。
3. 记下 HeyGem 在你电脑上的数据目录（官方默认一般是 D:\duix_avatar_data 或 D:\heygem_data 这类位置）。
   工作台通常能自动找到；如果后面自测时提示“找不到对口型数据目录”，
   用记事本打开工作台文件夹里的 config.json，把 "video_data_dir" 后面的引号里填上 face2face 数据目录，例如：
       "video_data_dir": "D:/heygem_data/face2face",
   （路径里用正斜杠 /）


第 4 步：申请阿里云百炼的 API Key（声音克隆和配音）
-------------------------------------------------
1. 登录阿里云，开通“阿里云百炼”（大模型服务平台）。
2. 在百炼控制台找到 API-KEY 管理，创建一个 API Key，复制下来。
   - 按量计费，具体价格以百炼控制台为准。
   - Key 相当于密码，不要发给别人、不要发到群里。
3. 在工作台文件夹里，把 config.local.example.json 复制一份，改名为 config.local.json。
4. 用记事本打开 config.local.json，把
       "api_key": "在这里填阿里云百炼（DashScope）的 API Key"
   引号里的中文换成你的 Key，保存。
   （保存时编码选 UTF-8；只改引号里面的内容，别删掉引号和逗号。）


第 5 步（可选）：大模型接口
---------------------------
填了大模型接口，工作台可以：自动提炼标题、识别每句情绪、规划信息卡片和重点词。不填也能正常出片，只是这些会用简单规则代替。
在 config.local.json 的 "llm" 里填：
- base_url：接口地址（例如 https://xxx/v1）
- api_key：接口的 key
- model：模型名
- api_format：一般填 openai；如果你的接口是 Anthropic（Claude）原生格式，填 anthropic
- proxy：填 direct 表示不走系统代理；需要代理就填 http://127.0.0.1:端口号
不需要大模型，就把 "llm" 这一段删掉，或者保持 base_url 为空。
填好后双击工作台文件夹里的「测试大模型.bat」检查能不能连上。


第 6 步：放素材
---------------
1. 数字人视频 → 放进 工作台文件夹\00_素材库\数字人\
   - 正脸、光线稳定、嘴巴不被挡住，每条 15 秒以上，越清晰越好（1080p 竖拍或 4K 横拍）。
   - 同一个人的多条视频按“名字-序号”命名，例如：小王-1.mp4、小王-2.mp4、小王-3.mp4
     两条以上会自动成组，随机混排，不会出现倒放。
2. 声音录音 → 放进 工作台文件夹\00_素材库\声音\
   - 15~20 秒，安静环境、没有背景音乐、连续自然地说话。
   - 开头就要是清楚的讲话（工作台只取前 20 秒做克隆）。
   - 文件名就是声音的名字，例如：我的声音.m4a（wav、m4a、mp3 都可以）。
3. 画中画素材（截图、录屏，可选）→ 之后在网页的“素材与声音”页上传即可。
4. 统一封面照（可选）→ 放一张 3:4 的半身照到 工作台文件夹\engine\assets\covers\my_cover.jpg
   没有这张图的话，封面会自动从视频里挑一个好看的画面。


第 7 步：自测
-------------
1. 先打开 Docker Desktop，确认 HeyGem 在运行。
2. 双击工作台文件夹里的「一键测试HeyGem.bat」。
   它会走一遍：克隆你的声音 → 合成一句话 → 对口型。
   结果和报告在 工作台文件夹\04_工程\_HeyGem测试\ 里，报告文件是“测试报告.txt”。
3. 测试通过，说明全套都能用了。没通过的话，把报告内容发给 AI 助手，或对照 references\troubleshooting.md 排查。


第 8 步：开始使用
-----------------
1. 双击「启动工作台.bat」，浏览器会自动打开 http://127.0.0.1:8790
   （第一次启动会自动下载缺少的依赖，稍等一会儿；这个黑色窗口不要关，关了工作台就停了。）
2. 在“文案与试听”页：
   - 标题：填“第一段 第二段”（中间一个空格就是分行位置），开场大字、封面和文件名都用它。
   - 文案：一句一行粘进去，点“拆成句子”，逐句点 ▶ 试听，每句可以选情绪和语速。
   - 右边选数字人素材、声音、风格包（暗夜橙光 / 暗夜科技 / 律师·律政金），选好输出画幅。
   - 点“满意，开始生成”。
3. 在“剪辑任务”页看进度。成片在 工作台文件夹\05_成片\<日期>\ 里，竖屏、横屏视频和两张封面都在这里。
4. 对口型最慢：1 分钟左右的文案，整条做完大约需要几十分钟，取决于显卡。


常用操作
--------
- 重新剪辑：任务完成后点“重新剪辑”，配音和对口型直接复用，只按新设置重剪，几分钟出片。
- 标题与封面：任务完成后点“🎨 标题与封面”，可以改文字、字体、字号、颜色、位置、背景虚化，封面保存后马上重画。
- 音频纠正：视频里读错一个字时，在“音频纠正”页上传音视频，框选那句，输入正确文字，用你的声音重读替换。
- 律师风格：风格选“律师·律政金”后，会出现律师姓名、律所的输入框。


遇到问题
--------
- 看日志：
  任务日志：工作台文件夹\04_工程\<任务文件夹>\任务日志.txt
  剪辑日志：同一个文件夹里的 剪辑日志_竖屏.txt / 剪辑日志_横屏.txt
  网页报错：工作台文件夹\06_日报\工作台日志.txt
- 常见问题和处理办法：aiup-workbench\references\troubleshooting.md
- 最常见的三个：
  1) 改了设置但成片没变化 → 关掉黑色窗口，重新双击「启动工作台.bat」。
  2) 报“页面文件太小”或内存不足 → 重启电脑；C 盘清出 20GB 以上空间；虚拟内存设为“自动管理”。
  3) 声音不像本人 → 换一段更安静、更连续的 15~20 秒录音。
