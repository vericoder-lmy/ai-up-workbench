# 常见问题（都是实际遇到过的）

先看日志：任务日志 `04_工程\<任务>\任务日志.txt`、剪辑日志 `04_工程\<任务>\剪辑日志_竖屏.txt` / `剪辑日志_横屏.txt`、网页接口日志 `06_日报\工作台日志.txt`。

| 现象 | 原因 | 处理 |
|---|---|---|
| 改了代码 / 点了“重新剪辑”，成片没变化 | 旧的工作台进程还开着，跑的是旧代码 | 双击 `启动工作台.bat`，启动器会自动关掉旧版本（有任务在跑时不会关，等它跑完） |
| 网页里报 `xxx() takes N positional argument but M were given` | 工作台进程里缓存着旧版引擎模块 | 同上，重启工作台 |
| `[WinError 1455] 页面文件太小` / `Cannot allocate memory` / `malloc ... failed` | 整机内存或虚拟内存不够（Docker/HeyGem 本身很吃内存，失败的进程可能残留） | 重启电脑；C 盘留 20GB 以上；虚拟内存设为“自动管理所有驱动器的分页文件大小”；`config.json` 的 `render.workers` 调成 1 |
| 成片里人物有倒放 / 来回重复的动作 | 只有一条很短的数字人素材，HeyGem 在循环 | 多录几条，按 `名字-1/2/3` 命名成组 |
| 脸部糊、眼睛和头发不清楚 | HeyGem 会重画整张脸 | 确认 `config.json` 的 `lipsync.restore` 为 true（画质还原）；素材本身要清晰 |
| 嘴部比周围糊 | 默认送 HeyGem 的是 720p，嘴部贴回时放大了 | 素材是 1080p 时，生成设置里“对口型清晰度”选 1080p（显存不够会自动退回 720p）；脸在画面里越大越清楚 |
| 多音字读错（如“藏房产”读成 zàng） | 配音模型猜错读音 | “读音纠正”词典加一条“藏房产=隐藏房产”；已出片的用“音频纠正”只重配那一句 |
| 声音克隆不像本人 | 参考录音有噪音 / 音乐，或开头不是讲话 | 换一段 15~20 秒安静、连续说话的录音（工作台只取前 20 秒）；可用 `测试声音克隆.bat` 对比不同模型 |
| 配音报 `Model not exist` | 百炼下线了某个旧模型 | `config.json` 的 `voice.engine` 用 `qwen_audio`，`voice.audio_model` 填控制台里可用的 qwen-audio TTS 模型 |
| 大模型相关功能没生效（标题是第一句、没有情绪建议、信息卡片很简单） | 大模型没配、额度用完、或网络 / 代理问题 | 双击 `测试大模型.bat` 看具体原因；不影响出片，会用规则版 |
| 大模型偶尔报 `Connection reset` | 中转站中途断开 | 已自动重试一次；还失败就过会儿再“重新剪辑”。失败的规划不会缓存 |
| 中转站返回 1010 / 403 | 被 Cloudflare 拦了默认 UA | 代码里已带浏览器 UA；仍不行换接口地址或走代理（`llm.proxy`） |
| 对口型一直卡住 | HeyGem 容器异常 | 工作台会在输出 10 分钟不增长时自动重启容器重试；手动可在 Docker Desktop 里重启容器 |
| 找不到对口型数据目录 | 自动识别 Docker 挂载失败 | 在 `config.json` 填 `heygem.video_data_dir`（宿主机上 face2face 数据目录） |
| 画面文字被截断 / 出框 | 标题太长 | 标题用“第一段 第二段”控制在每段 8 字左右；或在“🎨 标题与封面”里手动改文字和字号 |
| 封面照片不对 | 风格默认用统一封面照，或从视频挑帧 | “🎨 标题与封面” → “封面照片”里选来源，或单独上传一张 |
| 网页“声音”下拉框找不到 | 数字人素材太多把面板撑长了 | 右侧面板往下滚；同组素材只显示一张组卡片 |
